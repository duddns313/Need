지도 조회 키 — 넣으면 좋고, 없어도 됩니다

카드 명세서에는 알레스구떼, 가또블랑코 같은 상호만 찍힙니다. 이게 식당인지 미용실인지는 지도에 물어보면 바로 압니다. 키를 넣으면 상호명만 보내서 업종을 확인합니다 — 금액·날짜·계좌번호는 나가지 않습니다.

카카오 키 받는 법 (5분)
  1. developers.kakao.com 접속 → 카카오계정으로 로그인
  2. 상단 내 애플리케이션 → 애플리케이션 추가하기 → 앱 이름은 아무거나(예: 가계부), 사업자명은 본인 이름
  3. 만든 앱 클릭 → 앱 키 → REST API 키 복사
    JavaScript 키가 아니라 REST API 키입니다. 가장 흔한 실수예요.
  4. 앱 설정 → 플랫폼 → Web 플랫폼 등록 → 사이트 도메인에 http://localhost:8734
  5. 제품 설정 → 카카오맵 → 사용 설정 ON
    이걸 빼먹으면 조회가 안 됩니다.
  6. 복사한 키를 위 칸에 붙여넣고 저장
네이버 키로 대신하기
  1. developers.naver.com → 로그인
  2. Application → 애플리케이션 등록
  3. 사용 API에서 검색을 반드시 선택, 환경은 WEB 설정, URL은 http://localhost:8734
  4. 발급된 Client ID와 Client Secret을 아래에 입력
