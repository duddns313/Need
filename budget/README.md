# 부부 공동 가계부

뱅크샐러드 엑셀을 올리면 부부 것을 합쳐서 정리해 주는 프로그램입니다.
내 PC 안에서만 돌고, 거래 내역은 밖으로 나가지 않습니다.

---

## 처음 시작하기 (3단계)

### 1단계 — 코드 받기

브라우저에서 **https://github.com/duddns313/Need** 에 접속합니다.

1. 화면 위쪽 가지 모양 아이콘(브랜치 선택)을 눌러 **`claude/couple-budget-app-plan-bva99w`** 를 고릅니다
2. 초록색 **`< > Code`** 버튼 → **Download ZIP**
3. 받은 zip 파일을 **압축 해제**합니다 (바탕화면 등 원하는 곳에)

> zip 안에 `budget` 폴더가 있습니다. 그 안에 `시작.bat` 이 들어 있습니다.

### 2단계 — 파이썬 설치 (한 번만)

이미 있으면 건너뛰세요.

1. **https://www.python.org/downloads/** 접속
2. 노란 **Download Python** 버튼 클릭
3. 설치 화면 **맨 아래 `Add python.exe to PATH` 를 꼭 체크**한 뒤 설치
   > 이걸 안 하면 다음 단계에서 "파이썬이 없습니다"가 뜹니다.

### 3단계 — 실행

`budget` 폴더 안의 파일을 더블클릭합니다.

| 사용 중인 컴퓨터 | 더블클릭할 파일 |
|---|---|
| 윈도우 | **`시작.bat`** |
| 맥 | **`시작.command`** (처음 한 번은 우클릭 → 열기) |

검은 창이 뜨고, 잠시 뒤 브라우저에 가계부가 열립니다.
**끄려면 검은 창을 닫으면 됩니다.**

---

## 쓰는 순서

1. **설정** 탭 → 두 분 이름을 넣고 저장
2. **파일 올리기** 탭 → 뱅크샐러드 엑셀을 각각 올리기
   - 뱅크샐러드 앱 → 더보기 → 가계부 내보내기 → 기간 최근 1년
   - 한 명 것만 올려도 됩니다
3. **정리하기** 탭 → 모르는 가게가 남아 있으면 여기서 채우기
   - **설정에 카카오 키를 넣어두면** `지도에서 업종 찾기` 버튼 한 번으로 대부분 자동입니다
4. **대시보드** 탭 → 결과 보기, 필요하면 **엑셀 내려받기**

---

## 폰에서 쓰기

가계부는 PC 안에서만 돌기 때문에, 켜야 폰에서 접속됩니다.

1. PC에서 가계부를 켜고 **설정** 탭으로
2. **폰에서 접속 허용**을 체크하고, **접속 암호**(숫자 4자리 이상)를 정합니다
3. 저장하면 화면에 `http://192.168.x.x:8734` 같은 **주소가 나옵니다**
4. 검은 창을 닫고 가계부를 **다시 켭니다** (설정을 적용하려면 필요합니다)
5. 폰 브라우저 주소창에 그 주소를 입력 → 암호를 넣으면 열립니다

폰 브라우저에서 **홈 화면에 추가**를 하면 앱 아이콘처럼 쓸 수 있습니다.

> **PC가 켜져 있어야 폰에서 보입니다.** 같은 와이파이에 있는 기기만 들어올 수 있고,
> 인터넷에는 노출되지 않습니다. 그래도 통장 내역이라 암호를 꼭 정하세요.

## 평소와 다른 큰 거래

자동차를 사거나 보증금을 넣은 달은 지출이 평소의 몇 배가 됩니다.
그대로 두면 평소 씀씀이를 알 수 없고, 추이 그래프도 그 한 달 때문에 나머지가 눌립니다.

**정리하기** 탭에 그런 거래를 모아 보여줍니다. 왜 걸렸는지도 같이 나옵니다 —
예: *"쇼핑 평소 24,400원인데 이번엔 46배"*.

- **일회성** — 평소 계산에서 뺍니다 (합계에는 그대로 남습니다)
- **평소 지출** — 그냥 둡니다

대시보드에서 **일회성 빼고 보기** 버튼으로 평소 씀씀이만 볼 수 있습니다.
잘못 눌렀으면 정리 화면에서 되돌릴 수 있습니다.

## 카카오 키는 왜 넣나요 (선택)

카드 명세서에는 `알레스구떼`, `가또블랑코` 같은 **상호만** 찍힙니다.
이게 식당인지 미용실인지는 지도에 물어보면 바로 압니다.

키를 넣으면 **상호 이름만** 지도에 보내서 업종을 확인합니다.
**금액·날짜·계좌번호·카드번호는 어떤 경우에도 나가지 않습니다.**

받는 방법은 **설정 화면 안에 단계별로 적어놨습니다.** 무료이고 5분 걸립니다.
안 넣어도 프로그램은 그대로 돌아갑니다 (모르는 가게를 손으로 정해주면 됩니다).

## 자주 나오는 문제

| 증상 | 해결 |
|---|---|
| `[ERROR] Python is not installed` | 2단계에서 `Add python.exe to PATH` 체크를 빠뜨린 경우입니다. 파이썬을 지우고 다시 설치하면서 체크하세요 |
| `'...'은(는) 내부 또는 외부 명령이 아닙니다` 가 여러 줄 | 오래된 `시작.bat` 입니다. ZIP을 다시 받으세요 (2026-08 이전 버전에서 한글 인코딩 문제가 있었습니다) |
| `can't open file ...\budget\budget\run.py` | 위와 같은 원인입니다. ZIP을 다시 받으세요 |
| 검은 창이 떴다가 바로 닫힘 | 창에 뜬 메시지를 캡처해서 알려주세요 |
| `서버를 시작하지 못했습니다` | 가계부가 이미 켜져 있습니다. 브라우저에서 `http://127.0.0.1:8734` 로 접속하세요 |
| 브라우저가 안 열림 | 주소창에 `http://127.0.0.1:8734` 를 직접 입력하세요 |
| 지도 조회 버튼이 회색 | 설정에 카카오 키가 없습니다. 설정 탭에서 넣으세요 |
| 조회를 눌러도 안 잡힘 | 카카오 개발자 사이트에서 **제품 설정 → 카카오맵 → 사용 설정**이 켜져 있는지 확인하세요 |

## 내 데이터는 어디에 있나요

`budget/budget_data/` 폴더 하나에 전부 모여 있습니다.

| 파일 | 내용 |
|---|---|
| `state.json` | 올린 거래 내역 |
| `settings.json` | 이름, 정산 기준, 키 |
| `user_rules.json` | 내가 정한 분류 규칙 |
| `places_cache.json` | 지도에서 찾은 업종 (같은 가게를 두 번 조회하지 않으려고) |
| `exports/` | 내려받은 엑셀 |

**이 폴더째 복사하면 백업이 끝납니다.** 다른 PC에 옮길 때도 이 폴더만 덮어쓰면 됩니다.

## 폴더 구조 (참고)

```
budget/
  시작.bat / 시작.command   ← 더블클릭
  run.py                     실행 진입점
  app/                       프로그램 본체
    parser.py                뱅크샐러드 엑셀 읽기
    classifier.py            규칙으로 분류
    places.py                지도에서 업종 조회
    ai_classify.py           Claude에게 물어보기 (선택)
    couple.py                부부간 이체 상계, 정산
    aggregate.py             집계
    excel.py                 올인원 관리표 만들기
  rules/                     분류 규칙
  design/                    설계서, 키 발급 가이드
  tools/                     터미널용 도구 (안 쓰셔도 됩니다)
```
